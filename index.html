Deploying to GitHub Pages

TracePad is a standalone client-side web app. You can host it completely free on GitHub Pages in under two minutes:

  1. 1. Save this file: Save this file as index.html.
  2. 2. Push to GitHub: 
    git init
git add index.html
git commit -m "Initial TracePad release"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO_NAME.git
git push -u origin main
  3. 3. Activate Pages:

    In your GitHub repo, go to Settings → Pages. Set Source to Deploy from a branch, select main, and click Save.
